# Surface: portfolio home (single page)

Mode: Experience. Audience: recruiters and hiring managers judging an Android engineer in under a minute. Action: email, or click through to GitHub / LinkedIn. Pinned by user: first screen shows identity + current role + contact; avoid gimmick, generic dark dev template, bland résumé, hard-to-skim. Content: DatoCMS (projects, timeline, skills, certificates), schema fixed.

## Direction contract

THESIS: The career as a provenance record: one continuous ribbon-red custody line carries every role, dated, to the present post. Refuses the dark-gradient hero + equal card grid developer template and the plain white résumé.

OWN-WORLD: Archival buff laid-paper ground with faint grain; ribbon red (#A3141F) as the single custody line, primary action and display ink; unwoven gray for study/secondary passages; ledger taupe rules; condensed high-contrast ledger serif display (Instrument Serif), Spectral text and italics, Spectral SC tracked dated small caps; red bookmark tabs on section heads; a faded circular ink stamp; screenshots mounted on mats like catalogued documents.

STORY: Visitor learns who (Phyo Lin Mg), what (Android engineer, web as range), where now (SDK Developer, TicketRecipe), sees the dated path that got him there, opens real shipped work tied to the roles it came from, and emails.

FIRST VIEWPORT: Left rail (desktop): bookmark mark + name, section index with ringed-dot active state, accession card (current post, practice, Android since), stamp. Main: H1 name in red display ~6rem, italic one-line claim, ringed "Now" line with current post from CMS, ribbon-tag Email button + outlined GitHub / LinkedIn / Medium tags. Below, the career panel with vertical red tab: the ribbon runs left (2015) to right (Present), nodes dated in small caps, solid for work, dashed gray for study. Right column: featured exhibit, the project linked to the most recent role, mounted with caption card.

FORM: Provenance ribbon (dealt challenger, competitive, chosen by user on second hand). seed:643cb5f450aeb72f
Signature interaction: the ribbon draws itself from origin to the present on load (stroke reveal, exponential ease-out; nodes ink in as it passes); each node is a link to its full entry in the record. Reduced motion: drawn at rest.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
